2. Консоль RuStore: первая публикация

Через API нельзя создать новую карточку: черновик версии создаётся только у приложения, у которого уже есть активная версия. Поэтому первая версия — вручную в консоли, все следующие — скриптом rustore/publish.py. Справка: «Публикация приложения».

1
Войти в console.rustore.ru под ролью «Владелец компании» (только она может добавить новое приложение) → Приложения → Добавить приложение → название «Мадридиста».
2
Загрузить версию → APK: madridista-1.0.0-release.apk. Выбираем APK, а не AAB: APK уже подписан нашим ключом и RuStore публикует его как есть. Для AAB RuStore подписывает сборку сам, и сначала пришлось бы передать ему ключ (ZIP из утилиты PEPK + сертификат, справка про AAB). Приложение весит меньше 1 МБ — выгоды от AAB нет. AAB лежит рядом на всякий случай. Пакет и подпись у всех следующих версий должны совпадать с первой, versionCode — расти (справка про подпись).
3
Тип — «Универсальный» (телефоны и планшеты), не «Только для ТВ». Бесплатное.
4
Карточка: название, краткое и полное описание, «Что нового» — из раздела 3 (копировать как есть). Категория — «Спорт» (вторая — «Новости»). Теги — «Агрегаторы новостей», «События» (тег «Футбол» в RuStore только для игр).
5
Возраст — 12+ (справка). Обоснование: свои разделы (матчи, статистика, игры) — 0+, но в приложении показываются тексты новостей сторонних спортивных СМИ без нашей премодерации (травмы, конфликты, эпизоды матчей) — по 436-ФЗ это эпизодические ненатуралистичные описания, допустимые для 12+. Ставок, платежей, чата между пользователями нет. Если хотите 6+ — тоже защитимо, но модератор вправе поднять рейтинг.
6
Иконка — icons\icon-512.png (512×512, без прозрачности, совпадает с иконкой на устройстве). Скриншоты — 9 файлов из screenshots\ строго по порядку имён (01 … 09), все вертикальные 1080×1920 (9:16), PNG до 1 МБ.
7
Контакты разработчика (нужно хотя бы одно): сайт https://realmadridfan.ru; email — если решите (см. TODO). Отдельного поля для политики конфиденциальности в форме нет: ссылка стоит в конце полного описания и внутри приложения (Профиль → «Политика конфиденциальности»), как требует правило 5.1.
8
Безопасность данных (декларация): см. раздел 4 — что собираем и зачем. Разрешения: только «Интернет».
9
Комментарий для модератора — строка из раздела 5 (143 символа, лимит 180). → «Отправить на модерацию». Проверка — до 72 часов. Пока идёт модерация, не меняйте сайт в той части, что видит модератор.

8. Следующие версии — через API

Ключ API один на аккаунт (лежит в проекте F1, никуда не копируется). Скрипт без --yes только показывает, что сделает. Запуск: PYTHONIOENCODING=utf-8 python rustore/publish.py …

  1. поднять versionCode/versionName в android/app/build.gradle.kts, собрать assembleRelease;
  2. draft --card rustore/card.json --yes (тексты, «Что нового» из rustore/whats-new.txt, комментарий — из файла с кодом);
  3. upload-apk …/app-release.apk --yes; при необходимости upload-screens rustore/screenshots --yes, upload-icon rustore/icon-512.png --yes;
  4. commit --yes — отправка на модерацию. Проверить: status.

Справка API: авторизация, черновик версии, скриншоты v2, иконка. Правила модерации: требования к приложениям.
